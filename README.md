# WorkHoursApp

Приложение для учёта рабочего времени на Android и Windows. Главная задача — записывать часы. Учёт оплаты и тарифы включаются отдельно для нужных проектов; без них check-in и отчёты по времени работают так же. Исходный код открыт под лицензией MIT.

## Что уже работает

- Проекты с необязательным учётом оплаты. По умолчанию сохраняются только часы; при включении оплаты доступны несколько почасовых тарифов.
- История проекта показывает, когда включали учёт оплаты и добавляли тарифы.
- Менеджер плана со списком недели и календарём месяца; выбранный вид сохраняется. Плановую смену можно перенести или отменить до check-in. Отмена с причиной остаётся в истории; после check-in перенос и отмена дня запрещены.
- Предварительный check-in; тариф выбирается только для проекта с оплатой. Время отметки сохраняется отдельно от учтённого начала.
- Локальное напоминание Android о check-in в начале плана; после предварительного check-in — о подтверждении начала; после начала работы — о check-out в ожидаемый конец смены.
- Check-out с указанием окончания и неоплачиваемого перерыва.
- Статусы смен с иконками, а на экране «Сегодня» — отсчёт до планового начала или конца. Фактическое время показывается отдельно от плана. Отклонения до 20 минут сопровождаются мягким предупреждением, более значительные — заметным предупреждением с возможностью указать причину. Пересекающиеся учтённые интервалы разных смен не сохраняются.
- Исправление плановой, ожидающей, активной и завершённой смены с обязательной причиной. Исходные отметки сохраняются; изменения времени, проекта, тарифа и перерыва видны в истории смены. При изменении ожидающей смены напоминание переназначается.
- Отчёты за день, неделю, месяц и выбранный период: оплачиваемые часы и суммы по валютам. Выбранный отчёт можно сохранить в CSV для табличной программы на ПК.
- Локальная база SQLite. Резервная копия шифруется паролем (AES-256-GCM, PBKDF2) и сохраняется через системный выбор файлов. Файл можно сохранить в доступный на устройстве облачный диск и открыть на другом Android или ПК. Перед восстановлением приложение проверяет пароль и целостность, показывает дату и количество записей. Старые незашифрованные JSON-копии также можно импортировать.
- Экран «О приложении» с именем создателя, версией установленного пакета и адресом публичного проекта.
- Интерфейс и напоминания на английском, русском, украинском, польском, испанском, турецком и узбекском (латиница). По умолчанию используется язык телефона; выбор сохраняется. Пункт «Язык приложения» находится в меню с тремя точками рядом с «О приложении». CSV экспортируется на выбранном языке.

## Ограничения текущей версии

Это рабочая ранняя версия. Переводы требуют проверки носителями языков. Автоматической синхронизации между устройствами пока нет: перенос данных выполняется вручную через резервный файл. Экспорт отчётов в PDF и редактирование названий проектов и ставок тарифов ещё не реализованы. Пароль копии не сохраняется: потерянный пароль восстановить нельзя. Старые JSON-копии остаются незашифрованными.

Уведомления требуют разрешения Android. Если точные будильники недоступны, напоминание может прийти с задержкой. Если разрешение на уведомления не дано, смена всё равно сохранится, но приложение покажет предупреждение.

## Сборка и проверка

При отправке коммита GitHub Actions выполняет `flutter pub get`, `flutter analyze`, `flutter test`, `flutter build apk --release` с постоянным ключом подписи и `flutter build windows --release`. APK доступен в артефакте `work-hours-release-apk`, комплект Windows — в `work-hours-windows` соответствующего запуска CI. Для Windows нужно распаковать весь комплект в одну папку и запускать `work_hours_app.exe`; один `.exe` без папки `data` и DLL-файлов не работает. Ключ подписи и пароли не хранятся в Git: локальная копия находится в игнорируемых файлах `android/workhours-release.jks` и `android/key.properties`, а CI использует GitHub Secrets. Сохраните их отдельно в надёжном месте: без прежнего ключа будущие версии нельзя установить как обновление.

Версия `0.2.0-beta.1` была отладочной и имела другую подпись. Перед переходом с неё на подписанную release APK сохраните резервную копию, удалите старую APK, установите новую и восстановите данные.

Для локальной разработки нужны Flutter SDK и Android SDK:

```powershell
flutter pub get
flutter run
flutter build apk --debug
```

Код платформ находится в `android/` и `windows/`. На этом ПК Flutter SDK и Android SDK пока не установлены, поэтому проверка и сборка выполняются в GitHub Actions.
