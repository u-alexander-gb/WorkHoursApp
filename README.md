# WorkHoursApp

Приложение для учёта рабочего времени на Android. Один человек ведёт проекты, выбирает тариф для каждой смены и видит часы и начисления. Исходный код открыт под лицензией MIT.

## Что уже работает

- Проекты с несколькими почасовыми тарифами.
- Планирование смен на будущие дни.
- Предварительный check-in с выбором тарифа. Время этой отметки сохраняется отдельно от оплачиваемого начала.
- Локальное напоминание Android в запланированное время. Пользователь подтверждает фактическое начало и при необходимости меняет время начисления.
- Check-out с указанием окончания и неоплачиваемого перерыва.
- Отчёты за день, неделю, месяц и выбранный период: оплачиваемые часы и суммы по валютам. Выбранный отчёт можно сохранить в CSV для табличной программы на ПК.
- Локальная база SQLite. Экспорт полной резервной копии в JSON и восстановление из файла через системный выбор файлов. Файл можно сохранить в доступный на устройстве облачный диск и открыть на другом Android или ПК. Восстановление заменяет текущие данные после подтверждения.

## Ограничения текущей версии

Это рабочая ранняя версия. Автоматической синхронизации между устройствами пока нет: перенос данных выполняется вручную через резервный файл. Экспорт отчётов в PDF и редактирование существующих записей ещё не реализованы. Резервный JSON не зашифрован; храните его в защищённом месте.

Уведомления требуют разрешения Android. Если точные будильники недоступны, напоминание может прийти с задержкой. Если разрешение на уведомления не дано, смена всё равно сохранится, но приложение покажет предупреждение.

## Сборка и проверка

При отправке коммита GitHub Actions выполняет `flutter pub get`, `flutter analyze`, `flutter test`, `flutter build apk --debug` и `flutter build windows --release`. APK доступен в артефакте `work-hours-debug-apk`, комплект Windows — в `work-hours-windows` соответствующего запуска CI. Android APK — отладочная сборка, не релиз с личной подписью. Для Windows нужно распаковать весь комплект в одну папку и запускать `work_hours_app.exe`; один `.exe` без папки `data` и DLL-файлов не работает.

Для локальной разработки нужны Flutter SDK и Android SDK:

```powershell
flutter pub get
flutter run
flutter build apk --debug
```

Код платформ находится в `android/` и `windows/`. На этом ПК Flutter SDK и Android SDK пока не установлены, поэтому проверка и сборка выполняются в GitHub Actions.
