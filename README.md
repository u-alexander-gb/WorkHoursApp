# WorkHoursApp

Приложение для планирования смен, отметки начала и конца работы и расчёта часов по разным тарифам. Проект рассчитан на Android; общая кодовая база Flutter позволит добавить приложение для Windows.

## Состояние проекта

Сейчас подготовлены функциональный дизайн и стартовый исходный код Flutter. Сборка APK пока не выполнялась: на компьютере не обнаружены Flutter SDK и Android SDK. Android и Windows файлы платформ создаются командой `flutter create --platforms=android,windows .` после установки инструментов.

## Основной сценарий

1. Работник создаёт проект, например «Combo BV — сбор ягод», и добавляет доступные тарифы.
2. Планирует смены на неделю вперёд.
3. До начала смены выбирает проект, тариф и ожидаемое время начала. Это предварительная отметка, а не подтверждение фактического начала работы.
4. В назначенное время приложение напоминает подтвердить прибытие и начало работы.
5. В конце смены работник делает check-out. Приложение рассчитывает длительность и сумму.
6. Работник просматривает отчёты за день, неделю, месяц или произвольный период.

Подробности: [функциональный дизайн](docs/functional-design.md), [модель данных](docs/data-model.md), [план разработки](docs/implementation-plan.md).

## Разработка

Требуются Flutter SDK, Android SDK и инструменты сборки Windows для соответствующей платформы. После установки:

```powershell
flutter create --platforms=android,windows .
flutter pub get
flutter run
flutter build apk --release
```

Команда `flutter create` добавит стандартные файлы платформы к исходному коду проекта. Для выпуска APK на других устройствах понадобится настроить собственный ключ подписи Android.
