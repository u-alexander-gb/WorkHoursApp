# WorkHoursApp

Приложение для учёта рабочего времени на Android. Один человек ведёт проекты, выбирает тариф для каждой смены и видит часы и начисления. Исходный код открыт под лицензией MIT.

## Что уже работает

- Проекты с несколькими почасовыми тарифами.
- Планирование смен на будущие дни.
- Предварительный check-in с выбором тарифа. Время этой отметки сохраняется отдельно от оплачиваемого начала.
- Локальное напоминание Android в запланированное время. Пользователь подтверждает фактическое начало и при необходимости меняет время начисления.
- Check-out с указанием окончания и неоплачиваемого перерыва.
- Отчёты за день, неделю, месяц и выбранный период: оплачиваемые часы и суммы по валютам.
- Локальная база SQLite. Экспорт полной резервной копии в JSON и восстановление из файла через системный выбор файлов. Файл можно сохранить в доступный на устройстве облачный диск и открыть на другом устройстве. Восстановление заменяет текущие данные после подтверждения.

## Ограничения текущей версии

Это рабочая ранняя версия. Автоматической синхронизации между устройствами пока нет: перенос данных выполняется вручную через резервный файл. Приложение для Windows ещё не собрано. Экспорт отчётов в PDF/CSV и редактирование существующих записей ещё не реализованы. Резервный JSON не зашифрован; храните его в защищённом месте.

Уведомления требуют разрешения Android. Если точные будильники недоступны, напоминание может прийти с задержкой. Если разрешение на уведомления не дано, смена всё равно сохранится, но приложение покажет предупреждение.

## Сборка и проверка

При отправке коммита GitHub Actions выполняет `flutter pub get`, `flutter analyze`, `flutter test` и `flutter build apk --debug`. APK доступен в артефакте `work-hours-debug-apk` соответствующего запуска CI. Это отладочная сборка, не релиз с личной подписью.

Для локальной разработки нужны Flutter SDK и Android SDK:

```powershell
flutter pub get
flutter run
flutter build apk --debug
```

Код Android-платформы находится в `android/`. На этом ПК SDK пока не установлены, поэтому проверка и сборка выполняются в GitHub Actions.
