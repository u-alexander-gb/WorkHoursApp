# История версий

Версия приложения задаётся в `pubspec.yaml`. Название GitHub Release и тег
повторяют версию до знака `+`; число после `+` — номер сборки Android.
Правила и реестр выпусков: [Нумерация версий](docs/versioning.md).

## 0.2.0-beta.8+9 — 2026-11-09

- Исправлено сравнение beta-версий; номер Android-сборки больше не ломает проверку обновлений.
- Проверка обновлений теперь валидирует ответ GitHub, пропускает повреждённые записи и передаёт User-Agent.
- Добавлены тесты для порядка beta/stable-версий и некорректных тегов.

## 0.2.0-beta.7+8 — 2026-11-09

- Улучшена навигация по недельному расписанию и переходы между планом и
  текущей сменой.
- Добавлена проверка доступных обновлений с прямыми ссылками на Android APK и
  Windows ZIP.
- При переносе, удалении или завершении смены старые напоминания отменяются, а
  необходимые напоминания создаются заново; добавлены тесты этого жизненного
  цикла.
- GitHub Actions автоматически собирает подписанный Android APK, комплект
  Windows и контрольные суммы для GitHub Release.
- Для сценариев исправления смен, отчётов, резервных копий и миграций старых
  данных сохранено тестовое покрытие.

## 0.2.0-beta.4+5 — 2026-10-31

- Один check-in: при ранней отметке часы начинаются с планового времени без
  второго подтверждения. Старые ожидающие смены переводятся при обновлении.
- Плановые смены можно удалить из расписания с сохранением истории и Row ID.
  Row ID также включён в CSV и резервные копии.
- Общие настройки времени напоминаний о начале и конце смены.
- На пустой странице «Сегодня» добавлена ссылка на расписание.
- Тариф смены можно исправить после check-in с записью причины в историю.

## 0.2.0-beta.3+4 — 2026-10-30

- Отчёт CSV можно передать через системное меню «Поделиться» как вложенный файл.
  Почтовому приложению предлагаются тема с периодом и короткий текст письма;
  отправку подтверждает пользователь.
- Добавлены проверки отмены форм проекта и плана после ввода данных.
- Исправлено зависание теста интерфейса при обращении к SQLite.

## 0.2.0-beta.2+3 — 2026-10-29

- «Язык приложения» находится в меню с тремя точками рядом с «О приложении»;
  окно выбора показывает семь языков и системный вариант.
- Собственное окно «О приложении» показывает установленную версию и автора без
  служебного блока Flutter и текста лицензии.
- Android APK собирается в release режиме с постоянным приватным ключом.
- Для перехода с `beta.1` требуется резервная копия и переустановка из-за
  смены подписи.

## 0.2.0-beta.1+2 — 2026-10-29

Первый публичный предварительный выпуск.

- Добавлены английский, русский, украинский, польский, испанский, турецкий и
  узбекский языки. По умолчанию используется язык устройства; выбор сохраняется.
- Переведены интерфейс, напоминания Android и заголовки CSV.
- Сохранены планирование смен, check-in/check-out, исправления с историей,
  отчёты и защищённые резервные копии.
- Анализ, тесты, Android APK и Windows сборка прошли в GitHub Actions.

APK этого beta выпуска — отладочная сборка. Подпись отладочных APK может
отличаться между сборками; перед удалением старой версии сохраните резервную
копию данных.

## 0.1.0+1 — разработка, без публичного выпуска

Первый рабочий прототип учёта смен и часов.
