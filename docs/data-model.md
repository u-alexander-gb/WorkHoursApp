# Модель данных

Модель рассчитана на локальную SQL базу. Для Android и Windows потребуется единый слой доступа к данным. Все идентификаторы создаются на устройстве как UUID, чтобы будущий перенос между устройствами не зависел от автоинкрементных ключей.

## Сущности

### `projects`

`id`, `name`, `description`, `archived_at`, `created_at`, `updated_at`.

### `rates`

`id`, `project_id`, `name`, `hourly_amount_minor`, `currency_code`, `effective_from`, `archived_at`, `created_at`, `updated_at`. Сумма хранится в минимальных единицах валюты, например в центах.

### `shifts`

`id`, `project_id`, `status`, `planned_start_at`, `planned_end_at`, `pre_check_in_at`, `confirmed_at`, `credited_start_at`, `check_out_at`, `credited_end_at`, `timezone_id`, `note`, `created_at`, `updated_at`.

Отсутствующие значения допустимы согласно состоянию. Для завершённой смены обязательны `credited_start_at`, `credited_end_at` и хотя бы один тарифный участок.

### `shift_segments`

`id`, `shift_id`, `start_at`, `end_at`, `rate_id`, `rate_name_snapshot`, `hourly_amount_minor_snapshot`, `currency_code_snapshot`. В первой версии у смены один участок; структура позволяет позже менять тариф посреди смены без потери истории.

### `breaks`

`id`, `shift_id`, `start_at`, `end_at`, `paid`. Перерыв не может выходить за пределы подтверждённой смены или пересекаться с другим перерывом.

### `shift_events`

`id`, `shift_id`, `event_type`, `occurred_at`, `recorded_at`, `old_value_json`, `new_value_json`, `reason`. Журнал содержит планирование, предварительный check-in, подтверждение, check-out, отмену и исправления.

### `settings`

`key`, `value_json`, `updated_at`. Здесь хранятся предпочтения интерфейса и напоминаний. Пароль резервной копии здесь не хранится.

## Ограничения

- Названия проектов и тарифов не могут быть пустыми.
- Ставка не может быть отрицательной.
- Завершение должно быть позже начала; после вычета перерывов оплачиваемое время не может быть отрицательным.
- Архивирование проекта или тарифа не удаляет историю смен.
- Для каждой смены валюта участков должна совпадать, иначе итог показывается по валютам отдельно.
- Импорт резервной копии проверяет версию схемы и целостность до замены локальных данных.

## Пример

`Combo BV — сбор ягод` имеет тарифы `Сбор: €15/ч` и `Сортировка: €17/ч`. На 27 октября запланирована смена 10:00–18:00. Предварительный check-in сделан в 09:30 с тарифом `Сбор`. Подтверждение сделано в 10:00, check-out — в 18:00, неоплачиваемый перерыв — 30 минут. Учтённое время составляет 7 часов 30 минут, предварительный заработок — €112,50.
